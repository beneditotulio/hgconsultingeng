# HG Consulting & Engineering Website

Este repositório contém o website institucional da **HG Consulting & Engineering, Lda.**

## Estrutura

- `index.html` — Página principal do site, com informações sobre a empresa, serviços, projetos e formulário de contacto.
- `logotipo.jpg` — Logotipo da empresa.
- `banner.jpg` — Imagem de banner utilizada no topo do site (adicione este arquivo se ainda não existir).
- Documentos institucionais em formato `.doc` e `.docx`.

## Como visualizar

1. Faça o download/clonagem deste repositório.
2. Abra o arquivo [`index.html`](index.html) em qualquer navegador web.

## Funcionalidades

- Apresentação institucional da empresa.
- Lista de serviços oferecidos.
- Seção de projetos.
- Formulário de contacto.
- Links para redes sociais.
